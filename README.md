# Dashboard-de-vendas-feito-no-excel
Dashboard de vendas em Excel com tabelas dinâmicas, segmentações de dados e gráficos. Projeto de estudo.

Dashboard interativo de vendas construído no Excel como projeto de estudo, acompanhando uma videoaula. A planilha reúne vendas, itens vendidos, produtos, categorias, vendedores e filiais, e consolida os indicadores em uma aba de dashboard.

O que foi praticado: fórmulas para cruzar tabelas, tabelas dinâmicas, segmentações de dados (filtros interativos) e gráficos.

Ferramentas: Excel.
